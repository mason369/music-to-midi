## 音乐转 MIDI v1.10.0

本版将 MuScriptor 0.4.0、速度图、节拍纠错、量化和乐谱导出接入现有工作流，同时修复 Windows 项目保存冲突、MuseScore 平台插件弹窗和乐谱持续音丢失。

### 更新内容

- **MuScriptor 0.4.0**：直接使用固定官方推理源码；Large / Medium / Small 沿用对应权重与精度，同一次节拍分析供转写和编辑使用。
- **速度图贯通**：随演奏变化的速度图贯通试听、编辑、量化、项目重新打开和 MIDI/WAV/乐谱导出。工程变速缩放整张图，试听倍速独立控制。
- **不变速节拍纠错**：纠正 BPM、拍号、首拍与倍频时保留实际播放速度；同步 MIDI 轨道使用共同的原音偏移。
- **显式量化与导出选项**：五档网格 1/4、1/8、1/16、1/32、1/64，默认 1/32，增加强度、三连音和自动网格。切换选项不修改音符，执行量化才生效。短休止填补、空小节裁切和速度图平滑默认关闭，保留原始 MIDI。
- **乐谱与 Tab**：保留既有网格、同音高重叠、跨小节延音、拍号和非音符起点上的速度变化。吉他/贝斯指法检查弦位和持续音冲突；超过乐器容量时保留完整标准谱，并在乐谱 ZIP 中说明无法生成完整 Tab 的原因。
- **Windows 与播放修复**：解决项目清单原子保存的 WinError 5；隔离 MuseScore 子进程 Qt 环境并采用上游关闭顺序修复；修复跨端口音色加载和中英文项目界面更新。
- **和弦与 FLAC**：完整校验原音解码，兼容带首尾标签的原生 FLAC；和弦监听与原音共用帧时钟。

桌面、Space/Colab、独立 Web/API、Docker 和便携入口复用各自支持的共享能力。和弦栏仍属于桌面结果编辑器。

### 下载与启动

| 使用方式 | 下载文件 |
|---|---|
| Windows NVIDIA 完整便携包 | `MusicToMidi-Windows-GPU-Portable.wim.*` 的全部分卷 |
| Linux NVIDIA 完整便携包 | `MusicToMidi-Linux-GPU-Portable.tar.gz.part*` 的全部分卷 |
| Windows 浏览器前端 | `MusicToMidi-Windows-WebFrontend-Portable.zip` |
| Linux 浏览器前端 | `MusicToMidi-Linux-WebFrontend-Portable.tar.gz` |
| Docker 自托管 | `MusicToMidi-Docker-v1.10.0.zip` 或 `.tar.gz` |

完整便携包包含 App、WebBackend、WebFrontend 三个目录以及必需模型和运行时。桌面直接运行 App；Web 先启动 GPU 电脑上的 WebBackend，再启动 WebFrontend。轻量前端连接已有后端，不执行推理。

Windows：全部分卷放在同一目录，使用支持 WIM 的 7-Zip 从 `.wim.001` 解压到 NTFS。只解压第一卷是正常入口，但必须下载全部分卷。WinRAR 不支持 WIM。每个角色均需完整目录，不能只复制 EXE。

Linux：在全部分卷所在目录执行：

```bash
cat MusicToMidi-Linux-GPU-Portable.tar.gz.part* | tar -xz
```

Docker 包内提供 Compose、环境模板、管理脚本、中英文说明和固定镜像 digest；模型由显式初始化步骤准备。按包内 README 启动，Docker 镜像不包含完整便携包的离线权重。

所有附件校验值见 `SHA256SUMS.txt`。Linux 使用 `sha256sum --ignore-missing -c SHA256SUMS.txt` 校验已下载文件；Windows 使用 `Get-FileHash -Algorithm SHA256 <文件>` 与对应条目核对。

### 支持范围

- 官方完整包面向 Windows/Linux x86-64 与 NVIDIA CUDA；当前不发布 CPU、AMD/ROCm 或 Intel XPU 完整包。
- MuScriptor 与部分模型有非商业或其他使用限制，使用范围以包内 `THIRD_PARTY_NOTICES.md` 和组件许可证为准。
- 乐谱运行时使用包含关闭修复的官方 stable 通道 MuseScore 4.7.6 构建；本次核验时，上游 GitHub 正式发行仍待批准。
- 转写与和弦识别仍需结合原曲试听检查。自动生成的 Tab 不保证每个转写声部都能由六弦乐器完整演奏。

Release 附件只提供软件包与下载校验值，测试截图、验收报告、日志和内部构建清单不作为发行附件。

## Music to MIDI v1.10.0

This release integrates official MuScriptor 0.4.0, tempo maps, beat correction, quantization and score export into the existing workflows. It fixes Windows project-save conflicts, MuseScore platform-plugin dialogs and lost note durations in scores.

### Changes

- **MuScriptor 0.4.0:** pinned official inference source with the existing Large / Medium / Small weights and precision. One beat analysis is shared by transcription and editing.
- **Tempo maps:** performance-dependent timing remains consistent across playback, editing, quantization, reopened projects and MIDI/WAV/score exports. Project speed scales the whole map; audition speed is independent.
- **Beat correction without speed changes:** correct BPM, meter, downbeat and half/double-time interpretation while preserving playback speed. Synchronous tracks share the source-audio offset.
- **Explicit quantization and export options:** five grids from 1/4 through 1/64, default 1/32, plus strength, triplets and automatic grid selection. Changing options does not change notes until quantization is applied. Gap filling, leading-bar trimming and tempo smoothing remain off by default, retaining the original MIDI.
- **Notation and Tab:** preserve the grid, same-pitch overlaps, barline ties, meters and tempo changes between note onsets. Guitar/bass string assignments check sustained-note conflicts. Unplayable parts retain complete standard notation and an explanation inside the score ZIP.
- **Windows and playback fixes:** resolve the project-manifest WinError 5 race, isolate MuseScore's Qt environment, incorporate upstream shutdown-order repairs, and fix cross-port SoundFont loading and bilingual project updates.
- **Chords and FLAC:** verify complete source decoding, support native FLAC with leading/trailing tags, and keep chord monitoring on the source audio's frame clock.

Desktop, Space/Colab, standalone Web/API, Docker and portable entry points share supported functionality. The chord lane remains part of the desktop result editor.

### Downloads and startup

| Use | Download |
|---|---|
| Complete Windows NVIDIA bundle | Every `MusicToMidi-Windows-GPU-Portable.wim.*` volume |
| Complete Linux NVIDIA bundle | Every `MusicToMidi-Linux-GPU-Portable.tar.gz.part*` volume |
| Windows browser frontend | `MusicToMidi-Windows-WebFrontend-Portable.zip` |
| Linux browser frontend | `MusicToMidi-Linux-WebFrontend-Portable.tar.gz` |
| Docker self-hosting | `MusicToMidi-Docker-v1.10.0.zip` or `.tar.gz` |

Complete portable bundles include App, WebBackend and WebFrontend directories, required models and runtimes. Start App for desktop use. For Web use, start WebBackend on the GPU computer before WebFrontend. The lightweight frontend connects to an existing backend and does not perform inference.

Windows: keep every volume in one folder and extract `.wim.001` to NTFS with WIM-capable 7-Zip. Starting from the first volume is correct, but all volumes are required. WinRAR does not support WIM. Copy complete role directories, not just EXEs.

Linux: concatenate and extract all volumes with the command above. The Docker bundle includes Compose, environment templates, management scripts, bilingual instructions and pinned image digests. Model preparation is an explicit initialization step; Docker images do not contain the complete portable bundle's offline weights.

Compare downloaded files against `SHA256SUMS.txt`. On Linux, use `sha256sum --ignore-missing -c SHA256SUMS.txt`; on Windows, compare `Get-FileHash -Algorithm SHA256 <file>` with its entry.

### Support

- Official complete bundles target Windows/Linux x86-64 with NVIDIA CUDA. Complete CPU, AMD/ROCm and Intel XPU bundles are not published.
- MuScriptor and some models carry non-commercial or other restrictions. See bundled `THIRD_PARTY_NOTICES.md` and component licenses.
- The score runtime is an official stable-channel MuseScore 4.7.6 build containing the shutdown fix. Upstream GitHub publication was still awaiting approval at verification time.
- Review transcription and chord recognition against the original audio. Generated Tab cannot make every transcribed part playable on a six-string instrument.

Release attachments contain software packages and download checksums. Test screenshots, acceptance reports, logs and internal build manifests are not published as release assets.
