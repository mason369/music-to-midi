## 音乐转 MIDI v1.8.0

这次更新聚焦在**结果编辑、分声部导出与原音和弦显示**。完整 Windows / Linux GPU 便携包内含桌面 App、Web 后端、Web 前端、原生 CLI、模型和运行时；另提供可单独连接 GPU 后端的轻量 Web 前端，以及 Docker 自托管包。

### MIDI 结果编辑与导出

- 新结果默认显示并启用全部声部，清除上一份结果遗留的静音与独奏状态。桌面、Space、Colab 的结果编辑器支持同时独奏多个声部，手动静音与独奏选择分别保存。
- 一键导出**全部声部的 MIDI ZIP**，每个声部一个文件；导出反映当前编辑结果与工程 BPM。原有可听声部组合导出仍可使用。
- 独立 Web/API 的任务结果与已保存项目结果也提供分声部 ZIP。拆分保留音符配对，以及 tempo、拍号、控制器等事件的绝对 tick，不改写源 MIDI。
- 桌面与共享浏览器编辑器支持 `Space` 播放/暂停、`Shift+Space` 停止并回到开头；在输入框中键入空格不会触发播放。

### 原音和弦与播放反馈

- 桌面钢琴卷帘上方新增原音和弦栏。识别使用固定身份的官方 ChordMini BTC 模型与权重，按原音分析，并保留模型时间边界。可点击和弦试听；无和弦或未知标签不发声。
- 和弦按根音着色，完整显示升降号、大小调、七和弦、扩展和弦与转位；短片段的名称会错行显示并用引导线对应原片段，悬停可查看模型原始标签与起止时间。
- 修复播放跟随时和弦栏跳动。当前和弦高亮随播放头、暂停、跳转与缩放更新；长结果只绘制可见区域。
- 桌面、Space、Colab 的 MIDI 音符在播放、暂停与跳转时高亮；悬停显示音高、声部、力度与时间。反馈层不会修改音符或导出内容。

桌面和弦栏属于 Qt 桌面结果页；Space / Colab 获得共享 MIDI 音符反馈。独立 Web/API、Docker 与便携 Web 前端没有该钢琴卷帘，分声部导出通过各自结果/API 入口提供。

### 模型与发布包

- ChordMini 源码、配置和 `btc_model_best.pth` 使用固定版本与 SHA-256 校验；源码安装通过 `download_sota_models.py` 准备，完整桌面便携包内置。独立 Web/API 的分声部导出不需要 ChordMini。
- 七种既有处理模式、13 条分离后显式逐轨转写路线及原有模型保持可用。人声/伴奏与六声部分离仍先输出 WAV，MIDI 转写由用户逐轨发起。
- 完整 GPU 包内置 Python/CUDA 12.8 运行时、所需模型、FFmpeg、FluidSynth、SoundFont 与 MuseScore；运行需要与内置 PyTorch/CUDA 兼容的 NVIDIA 显卡和驱动，无需另装 Python 或 CUDA Toolkit。当前显卡与内置 PyTorch/CUDA 不兼容时会明确报错；本版不提供完整 CPU 包。
- 源码准备 MuScriptor 三档权重需要在三个 Hugging Face 模型页接受各自许可，并使用同一账户认证；不能匿名全自动下载。完整便携包已内置对应权重。
- Space 的 Pydantic 依赖已更新至与平台自动安装的 Gradio MCP 扩展兼容的版本，修复构建时的依赖解析冲突。
- Space 同步包补齐模型就绪探针模块，修复镜像构建完成后的启动导入错误。

## Music to MIDI v1.8.0

This release improves **result editing, per-part MIDI export, and source-audio chord display**. Complete Windows and Linux GPU packages contain the desktop App, WebBackend, WebFrontend, native CLI, models, and runtimes. Lightweight Web frontends and a Docker self-host package are also provided.

### Editing and export

- New results start with all parts visible and enabled, without mute/solo state inherited from a previous result. Desktop, Space, and Colab allow multiple soloed parts and retain manual mute and solo selections separately.
- Export **all MIDI parts in one ZIP**, one file per part, reflecting current edits and project BPM. Combined export of audible parts remains available.
- Standalone Web/API job and saved-project results also provide a parts ZIP. Splitting preserves note pairing and the original absolute ticks of tempo, meter, controllers, and other events without modifying the source MIDI.
- `Space` plays/pauses and `Shift+Space` stops and rewinds in the desktop and shared browser editors. Typing in an input field does not trigger playback.

### Chords and playback feedback

- A new chord lane above the desktop piano roll analyzes source audio with the pinned official ChordMini BTC model. Native time boundaries are preserved; clicking a chord auditions it. No-chord and unknown labels remain silent.
- Chords use root-note colors and show accidentals, major/minor and extended qualities, and inversions. Short segments receive complete staggered labels linked to their source intervals; tooltips retain the model label and timing.
- Playback follow no longer makes the chord lane jump. Current-chord highlighting follows playback, pausing, seeking, and zoom; large results paint only the visible region.
- Desktop, Space, and Colab highlight audible MIDI notes during playback, pause, and seeking. Hover details show pitch, part, velocity, and timing without changing notes or exports.

The chord lane belongs to the Qt desktop editor. Space and Colab receive the shared MIDI note feedback. Standalone Web/API, Docker, and portable Web do not contain that piano roll; their parts ZIP is exposed through their result/API paths.

### Models and packages

- ChordMini source, config, and `btc_model_best.pth` are pinned and SHA-256 checked. Source installs prepare them through `download_sota_models.py`; complete desktop portable packages include them. Standalone Web/API parts export does not require ChordMini.
- The existing seven processing modes and 13 explicit per-track routes remain available. Vocal/accompaniment and six-stem modes produce WAV first; users explicitly transcribe selected tracks to MIDI.
- Complete GPU packages include Python/CUDA 12.8 runtimes, required models, FFmpeg, FluidSynth, SoundFont, and MuseScore. A compatible NVIDIA GPU and driver are required; separate Python or CUDA Toolkit installation is unnecessary. Incompatible hardware fails visibly. No complete CPU package is released.
- Source preparation of the three MuScriptor checkpoints requires acceptance of each Hugging Face model-page license and authentication with the same account; anonymous fully automatic download is not available. The complete portable packages already include these checkpoints.
- Updated the Space Pydantic pins to match the Gradio MCP extra installed by the platform, fixing a build-time dependency resolution conflict.
- Added the model-readiness probe module to the Space sync bundle, fixing a startup import error after the image build.

After extraction, launch `MusicToMidi.exe` from App or use `MusicToMidiCLI.exe`. For Web access, start `MusicToMidiBackend.exe` on the GPU host before `MusicToMidiFrontend.exe`. The Linux archive likewise contains App, WebBackend, WebFrontend, and `MusicToMidiCLI`.
